# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-10-21
### Added
- Core `CheckoutSDK` class implementing client-side payment tokenization.
- Automated multi-provider failover routing and circuit breaker pattern.
- Strict Idempotency-Key enforcement for all transaction mutations.
- GitHub Actions CI/CD static verification pipeline.
