# Contributing to Checkout Flow SDK

Thank you for your interest in contributing to the Checkout Flow SDK project! Please follow these guidelines to ensure a smooth contribution process.

## Development Workflow
1. Fork the repository and clone your local copy.
2. Create a dedicated feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes using [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat(sdk): add new payment provider integration`
   - `fix(core): resolve network timeout handling`
4. Ensure all TypeScript type checks pass successfully.
5. Push to your branch and open a Pull Request against the `main` branch.
